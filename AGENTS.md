# Repository guidance

Before proposing or making changes, load the local [Niltavi project Skill](.agents/skills/niltavi-project/SKILL.md). Read the current shared sources in this order.

1. [Niltavi Rules](https://github.com/niltavi/niltavi-rules#readme), including the sections that apply to the task.
2. [Niltavi Skills](https://github.com/niltavi/niltavi-skills#readme), including the instructions for each applicable Skill.
3. [Niltavi UI](https://github.com/niltavi/niltavi-ui#readme), including the relevant shared UI source for interface work.

Apply repository-specific guidance alongside the shared rules. Write the primary documentation in English.
